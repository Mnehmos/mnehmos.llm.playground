# Experiment 31.2 · Installing into a trained host
Three fresh seeds (831211, 831223, 831227). Train only the separate written-operand routing task for 200 AdamW updates (96 rows per batch, LR .002) with reserved, zero converter maps and zero conversion readout. Validate host routing >=95% on held written forms or stop. The conversion maps are inactive during host-only training. Install the exact encoder and decoder by copying only their tensors into each host. Require held host logits to agree bit-for-bit, and ordinary conversion, isolated conversion, causal authority and equal-quantity performance to be exact at step zero. Reset the optimizer on post-installation forks for all arms, retaining matched fresh continuation streams.

Run A–F, the same six Experiment 30 policies, for 600 additional updates. The conversion partition excludes source unit 1 with written residue >=8 or destination unit 2, and uses a deterministically sampled visible half (RNG 830079), holding the other half for terminal testing. This partition differs from Experiment 30's source-unit-2 holdout. No withheld conversion examples as loss targets, patch training donors, or calibration traces. The terminal partition is public in code, evaluation deferred until all final reviews. Adjacent force/routing diagnostics use the prior recipe and remain visible. Show host retention, session-wise seed changes and endpoint contrast between frozen unrestricted and bounded/isolated, with D–F secondary. Three seeds and small finite evaluation justify replication descriptions without a confirmatory significance claim. Capacity was reserved in the host architecture; this does not demonstrate installation into an arbitrary unprepared network.
