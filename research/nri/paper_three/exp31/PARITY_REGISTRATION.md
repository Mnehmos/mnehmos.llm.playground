# Experiment 31.3 · Finite-state replication
Three fresh seeds (831301, 831307, 831311), four matched arms. A trainable exact state transitions and unrestricted competing residual, B frozen and unrestricted, C frozen and componentwise bounded to ±0.4, E frozen with independent conversion-style residual omitted from the decision. A learned two-layer transformer predicts sequence parity from written eight-bit sequences and supplies the competing output logits. The installed recurrent operation uses two 2x2 parameter matrices, identity and state swap, and iterates those matrices across eight token positions. The intervenable two-state vector after token four is replaced by the state from a donor's four-token prefix. Only the base suffix is then processed through the installed mechanism. The learned path still receives the original bits. Ordinary/held partitions follow the fixed shuffled order of all 256 sequences (RNG 38577, 160 training/48 visible/48 final). Outputs are binary so evaluate discriminating swaps that differ from unpatched truth, unpatched negative controls, identity and equal-state swaps with different prefixes. The C guarantee is at least 0.2 surviving margin with legal states. Unlike the modular converter, this task accumulates state recurrently along a sequence, but simple parity remains a finite toy problem.

600 AdamW updates at .002, batch 64, identical draws within a seed. Final holdout scored only after terminal review, and calibration only on visible inputs. Study measures whether isolated state and causal authority diverge, with bounded/isolated positivity checks at every step; no separate plasticity task. Use descriptive three-seed replication and preserve null results. Report step-grid collapse intervals and distinguish observed task-general replication from generalization to arbitrary neural programs.
