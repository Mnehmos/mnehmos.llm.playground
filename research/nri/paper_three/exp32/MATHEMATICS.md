# Additive-path margins

For an original written input x, the full output logits after a valid intervention setting programmed state q are z(x,q) = P(q) + R(x). Ordinary inference is the same expression with q equal to the state naturally computed on x. The target y must be specified by the operation and intervention. For every rival j different from y, let p_j=P_y-P_j, c_j=R_j-R_y. The target uniquely wins if and only if min_j(p_j-c_j)>0. An exact isolated program only establishes p_j>0. The two facts can therefore diverge. Equal logits are ties and do not have a unique winner independently of the implementation tie rule.

With attenuation alpha in [0,1], each rival imposes p_j-alpha*c_j>0. Rivals with c_j>0 impose alpha<p_j/c_j, rivals with c_j<0 impose alpha>p_j/c_j, and c_j=0 requires p_j>0. Intersect these strict half-lines with [0,1]. With an exact program all p_j>0, so the upper endpoint is the minimum ratio over positive c_j, or infinity if there is no such rival. If it is below one, attenuate more than one minus that endpoint. When the endpoint equals one, alpha=1 still ties. Frozen exact one-hot outputs have p_j=1. A bound |R_k|<=0.4 implies c_j<=0.8 and leaves a guaranteed margin >=0.2, on that legal domain only. Removing the branch gives c_j=0. An unrestricted branch with a loss penalty has no such guarantee.

For cross-entropy L=-z_y+log(sum_k exp z_k), differentiation gives dL/dR_j=softmax(z)_j-1[j=y]. A correct prediction means z_y exceeds other logits. At finite logits its probability is less than one. For K classes at z_y=m, z_j=0 otherwise, the target probability is exp(m)/(exp(m)+K-1) and the residual-gradient norm is sqrt(K(K-1))/(exp(m)+K-1). Larger confidence attenuates this gradient without making it exactly zero. Differentiating into residual weights multiplies this local gradient by the branch Jacobian. For the satisfied objective, L=max(0, 0.5-min_j(z_y-z_j)), the conversion loss and its gradient are zero strictly above the threshold. An ordinary margin trains ordinary decisions only. It is not a loss on causal structure.

Successful classification and nonzero confidence gradients do not prove that any given parameter update creates a bypass. Shared objectives can alter features, moment accumulation can move weights even with zero fresh gradient, and decoupled decay acts on current values. In the AdamW update, use the effective parameter change, not the instantaneous gradient, to distinguish these events. Experiment 29's replay and Experiment 31's zero-gradient replay test distinct causes. The new prospective objective comparison tests whether the confidence-seeking signal is necessary under an unbounded branch that also learns an out-of-domain special case. Neither a positive result nor a negative one makes a universal claim about gradient descent.

The retrospective instrument checks the algebra against actual argmax outputs, including attenuation under multiple strengths. This is a consistency check, not an independent forecast. The archived early points summarized behaviors but did not save all raw logits at steps 1, 5, 10, 20 or 50. Newly captured margin values on those early steps are prospective measurements rather than reconstructions of past runs.
