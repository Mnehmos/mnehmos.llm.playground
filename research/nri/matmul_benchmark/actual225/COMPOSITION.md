# MM-01F: exact symbolic composition

Exploratory continuation; source Rafael Pass, https://arxiv.org/html/2610.28627v2, Lemmas 3.2, 3.4, 4.1–4.2. Implements actual scalar same-left packing maps (primal and transposed dual) as sparse local edges. Balanced word indexing computes completion counts combinatorially without enumerating all words. Independent-left interpolation follows Lemma 3.4 at scalar base with one formal parameter, eta=epsilon^w. Tests retain balanced target words, not canonical variable renaming or all matrix-role exchanges.

Composition replaces the outer source evaluator with an inner packing, matching source types Full/Mid and lengths. For p=2d axes, the right encoder and decoder jointly have poles of degree at most p. At stage level j use epsilon^((p+1)^j), so inner errors remain positive degree after outer poles. A safe degree bound for k stages is (p+1)^k-1. The numeric reference uses that many plus one nonzero evaluations. SymbolicChain instead associates each sparse intermediate with its integer Laurent degree, merges equal (coordinate,degree) contributions, and extracts degree zero after cancellation; it rejects residual negative powers. The leaves use direct polynomial coefficient products. This avoids repeated evaluation of the whole graph for the tested chains, but is not a new rank bound or proof of cheaper general dense multiplication.

Run python test_composition.py and python depth_scaling.py with assertions enabled. Python 3.13.5. Initial local measurements: 3155 balanced rank/unrank checks (3146 exhaustive small words and 9 selected large words), 624 amplified output coordinates, 190 independent-left output coordinates (including 8 targets x 8 columns at a=b=1), 540 composition output comparisons across numerical and symbolic paths, 3 guard tests. Separate depth tests add 1596 output comparisons (7 depths x (6+222)), all exact. Same inputs per depth. Finite tests, not a formal proof of implementation correctness.
