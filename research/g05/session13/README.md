# G05 Session 13: Automatic observability and joint intervention discovery

## Main findings
1. A small shared learned policy can select contexts that expose a previously masked difference, but gains over strong non-neural search are modest. Observability is separate from finding an economical witness and verifying it.
2. Output-response diversity alone can select informative reference contexts for the actual historical neural readouts. A zero-output reference often hides four or all five sites. On the fixed reserved-source scan, the selected reference exposed 12 errors (4 and 8) at the acceleration-value port of two S11 34001_quotient heads with perfect ordinary predictions. Random and zero reference controls found none of those defects. This is a conventional observer operating on supplied ports, not a learned discovery of the native network's topology.
3. Single-site tests cannot certify joint computational competence. On 192 synthetic tasks with no single-site witness, frozen learned selectors found 147/192 and 156/192 joint witnesses, while threshold-hypothesis search found 162/192. Every accepted coalition is inclusion-minimal by explicit subset audit. No claim of global minimality for the adaptive methods.
4. The cost of verifying a coalition can overwhelm savings in discovering it. A new neural policy supervised on both witness probability and certificate-size targets improved hit rate and lowered its own cost with a size penalty, but did not beat random search under the registered 64-call unresolved-task penalty. Negative result preserved.

All methods use precomputed exact synthetic outputs as query simulators, not as input features.

## C. Joint intervention masks
280 synthetic 6/8-port tasks, 240 observable, 40 invariant. Seven families with additive cancellation, conjunction/product, redundant-path min, opposing products, inhibited product, lookup and impossible. Same frozen 1025-parameter selectors without fitting. First witness budget 16 additional masks including baseline separately, singleton-only and exhaustive controls. Of 240 observable, only 48 have any singleton witness; 192 require joint changes. Total hits: random 173, farthest 202, Bayesian 206, frozen A/B 193/202, singleton-only 48, full-then-singleton 203, exhaustive 240. On joint-only: 129,158,162,147,156,0,155,192 respectively. Every accepted coalition greedily reduced then explicitly tested against all strict subsets in increasing size; global cardinality minimum independently scored using true table. On all observable tasks mean actual unique scalar calls (fixed baseline cached) random 15.65, farthest 24.51, Bayesian 24.48, frozen A/B 17.32/18.25, exhaustive 56.28. Means include failed searches; lower cost with fewer successes is not superiority. Pure conjunction-like redundancy favored full mask. Opposing products and inhibition can cancel the full mask; no single fixed probe covers every family.

## D. Certificate-aware allocation
New independent training on 4/5/6-port functions, 5000 episodes, 166533 rows; two 1074-parameter MLPs seed 53031/32, 1000 AdamW updates. Learn witness probability and minimum positive submask cardinality conditional on positive witness. No truth tables at inference. Fresh 384 8/10-port tasks (336 observable, 48 impossible), including nested overlapping cancellation not trained. Registered scoring: 16 additional masks then exact local certificate, loss64 = actual unique scalar calls +64 for unresolved observable task, not a universal decision-theoretic optimum. Random 227/336, mean total 19.27, loss64 40.04. New probability-only A/B without full-first 288/292, mean total 49.66/63.67, loss64 58.81/72.05. Size penalty .5 A/B 273/284, mean total 29.79/36.54, loss64 41.79/46.45. Full-first + old neural B 279/336 loss64 72.59; exhaustive 336/336 loss64 168.71. No policy dominates random under the registered cost criterion. Size penalty helps each new model relative to its own unpenalized policy, but sacrifices hits. Exhaustive guarantees global minimum under the finite cube; adaptive certificates only inclusion minimum. All impossible controls have zero false witnesses. Redundancy cases can demand exponentially many subset observations for unrestricted exact certification; a monotonicity prior would alter this cost, not establish a general certificate.

## Next research question
Distinguish *where a defect exists* from *what combination exposes it*. Learn causal intervention proposals on actual internal native-transformer sites without supplied semantic grouping; separately test whether weak gradients arise from conditional observability or true representational insufficiency. Need a policy that estimates cost of obtaining a verified diagnosis, not merely probability of a nonzero difference. Treat cancellation, inactive branch and joint masking as distinct failure modes.
