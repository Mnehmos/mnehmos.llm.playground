# Research roadmap

The program has demonstrated bounded forms of interpretable mathematical computation, modular reuse and hybrid acquisition. It has not established autonomous general mathematical intelligence. The next stages should close the gaps rather than inflate parameter counts.

| Objective | Next qualification |
| --- | --- |
| Native generalization | Fresh initializations and task splits; separate canonical conversion, routing and decoder competence. Do not tune on examined sealed sets. |
| Cumulative mathematical learning | Compare identical discovery algorithms with frozen vs growing banks. Test basis changes, incompatible representations, retention, retrieval cost and unfamiliar mathematical families. |
| Developmental control | Predict capability-specific intervention effects before applying them. Include abstention, ordinary AdamW with the entire intervention/diagnostic budget, fixed policies and independent seed/task groups. |
| Mathematical discovery | Learn to propose, revise and combine partial typed programs, identify missing coordinates and choose distinguishing observations. Separate neural-only, neural-guided search and classical baselines. |
| Hybrid minimality | Use shared neural action scoring over typed candidate computations rather than one network per function family. Measure total system resources and a zero-neural baseline. |
| Track L | Establish real Lean 4 environment, typed proof-state interface, dependency-audited proofs and independently reserved discovery tasks. No kernel qualification until actually run. |
| Robust compiled attention / CPU optimization | Replicate on the actual NRI architecture; qualify perturbation robustness, causal preservation and end-to-end throughput. |
| Public research infrastructure | Import auditable session packages in isolated PRs, add automated smoke tests, preserve source manifests, decide licensing and publication scope, review before merging research branches. |

## Central unresolved question

Can a system autonomously identify which mathematical structure is missing, choose useful evidence, acquire and verify the structure, and reuse it at a lower total cost on subsequent tasks?

A successful answer requires prospective evaluation, not merely a good explanation of previously observed networks. No model promotion is justified by familiar accuracy alone. No larger optimizer sweep should substitute for demonstrating informative diagnostics and a useful intervention menu.

This roadmap is a proposed engineering and research agenda. It is not a claim that the listed experiments have already been executed.
